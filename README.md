# Speckitplus-Hackathon-II - The Ultimate Todo App

## Overview

This is a comprehensive, full-stack task management application built for the **Speckitplus Hackathon**. It demonstrates a complete evolution from a simple CLI tool to a scalable, containerized, and AI-powered microservices architecture.

The project is divided into **5 Phases**, each adding complexity and modern engineering best practices:
* **Phase I**: Python CLI Fundamentals
* **Phase II**: Full Stack Web App (FastAPI + Next.js)
* **Phase III**: AI-Powered Chatbot (Gemini Integration)
* **Phase IV**: Containerization & Orchestration (Docker + Kubernetes)
* **Phase V**: Cloud Deployment & Production Optimization

## 🛠 Tech Stack

### Backend & AI
* **Language**: Python 3.12+
* **Framework**: FastAPI
* **Database**: PostgreSQL (Neon DB) with SQLModel
* **AI Model**: Google Gemini 2.5 Flash (via OpenAI Agents SDK)
* **Containerization**: Docker & Kubernetes (Minikube for Dev)

### Frontend
* **Framework**: Next.js 16 (App Router)
* **Language**: TypeScript
* **Styling**: Tailwind CSS + Shadcn UI
* **Auth**: Better-Auth & JWT
* **State**: React Query + Context API

### Infrastructure
* **Frontend Hosting**: Vercel
* **Backend Hosting**: Hugging Face Spaces / Render
* **Database**: Neon (Serverless Postgres)
* **Orchestration**: Docker Compose / Minikube
